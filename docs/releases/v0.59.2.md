# Elyndra v0.59.2

## Hotfix

- Fixed a world-entry crash affecting non-Traditional-Chinese locales after accepting the World Contract.
- Root cause: `visibleTranslationPayload()` read `state.notes?.entries` before checking whether `state.notes` was already an Array; for Arrays, `.entries` is the built-in function and is not itself iterable.
- The locale runtime now accepts both the canonical notes Array and the legacy `{ entries: [] }` shape.
- Added regression coverage for Japanese/English translation payload generation with an empty notes Array.
- Browser cache contract advanced to `59002`; app version advanced to `0.59.2`.
