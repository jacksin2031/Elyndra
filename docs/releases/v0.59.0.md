# Elyndra v0.59.0

- Adds isolated runtime locales: Traditional Chinese, Simplified Chinese, English, and Japanese.
- Separates UI/display locale from each world's canonical source locale; language switching never rewrites Canon.
- Mid-session switches and loading a world authored in another locale require AI translation of the currently player-visible world corpus before gameplay can continue.
- Direct-provider and server-provider AI calls receive a request-local runtime language override so output stays in the selected language.
- Adds per-locale translation caches and prevents translations from one target language leaking into another.
- Moves the narrator out of the scene-art overlay into a dedicated structural row immediately above `Your Actions`, fixing the recurring narrator position fault.
