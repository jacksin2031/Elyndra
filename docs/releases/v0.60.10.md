# Elyndra v0.60.10

Japanese new-world creation hotfix based on the blocked v0.60.9 live manual acceptance.

- New worlds whose canonical source locale already matches the selected locale no longer run a blocking language-switch translation gate before the first scene.
- World-generation progress text and the world-ready notice are deterministically localized on first render.
- Explicit worldview text such as `魔法は希少` constrains style-mode magic intensity instead of being overwritten by the style preset.
- Adds regression coverage to the Node 20/24 Pages gate.

This release does **not** claim the Japanese manual acceptance is complete; the live flow must be rerun after deployment.
