# Elyndra v0.59.3

## Locale completeness hotfix

- World Contract now renders deterministically in Traditional Chinese, Simplified Chinese, English, or Japanese.
- Contract metrics, difficulty rules, unknown-state labels, origin, role, difficulty, and action buttons no longer inherit Traditional-Chinese presentation text in non-default locales.
- Added locale contamination detection so mixed output such as `眼前的風が...` is not trusted as already-localized Japanese.
- Same-locale worlds now send contaminated visible strings through the residual AI translation gate.
- Added permanent v0.59.3 regression coverage and advanced browser cache contract to `59003`.
