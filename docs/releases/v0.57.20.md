# Elyndra v0.57.20

- Progression suggestions only quote concrete, player-visible events with current-world/current-scene provenance.
- Quest titles, quest-stage/status events, and abstract objectives are not treated as observable event evidence.
- Unscoped or wrong-scene events fall back to direct observation, exploration, or available social actions instead of fabricated “visible effects”.
- Adds non-download regressions for quest-title leakage, scene provenance, and valid observable-event progression.
- Prior suggestions and template-like action text cannot recursively become new suggestions; nested quotation falls back to concrete scene observation.
