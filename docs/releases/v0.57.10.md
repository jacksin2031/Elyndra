# Elyndra v0.57.10

IAB download delivery hardening.

- AutoTest Debug/world downloads now prefer a same-origin Service Worker HTTP attachment response with `Content-Disposition`, avoiding `blob:` delivery when the page is controlled.
- The bridge registers at module load, uses `skipWaiting()` + `clients.claim()`, and serves the already-persisted IndexedDB AutoTest snapshot without rerunning a test.
- Blob/object-URL delivery remains a fallback only when Service Worker control is unavailable.
- Added unit coverage for HTTP-vs-Blob selection and a real Chromium first-click regression that writes both Debug and 2-world bundle files to disk, then verifies exact bytes and SHA-256.
