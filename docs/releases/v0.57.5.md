# Elyndra v0.57.5

Developer AI AutoTest export reliability update.

- AutoTest persisted snapshot can be saved with the File System Access API when available.
- Debug JSON and world JSON can be copied directly to the clipboard from the persisted snapshot panel.
- Clipboard fallback uses a temporary selection copy path when direct Clipboard API access is denied.
- Traditional browser download remains available as a fallback.
- FIRST_BUTTON now remains pinned to the first visible action button; free-text is only used when no action button is available.
- Existing persisted AutoTest snapshots can be reloaded and exported without rerunning the batch.
