# Elyndra v0.57.18

Embedded-browser AutoTest attachment delivery repair.

- Restores the controlled-browser same-origin Service Worker HTTP attachment navigation used by v0.57.12-v0.57.15.
- Removes the renderer-side `download` attribute from the controlled HTTP path so `Content-Disposition: attachment` remains authoritative for the host browser.
- The verification page now waits for Service Worker control before choosing its delivery lease; Blob/object-URL remains only the uncontrolled fallback.
- Existing IndexedDB AutoTest snapshots remain compatible and are not regenerated.
- Validation for this patch is limited to pure unit/static delivery contracts plus the full `test:nondownload` suite. No browser download proof is executed here; external delivery verification remains with Codex.
