# Elyndra v0.57.8

AutoTest export delivery reliability update. Existing IndexedDB AutoTest snapshots remain compatible and are not regenerated.

- Standard Blob/object URL + native `<a download>` is now the primary delivery path.
- A download click is reported only as `DOWNLOAD REQUESTED · NOT VERIFIED`.
- Success requires selecting the actual saved file back into Elyndra and matching filename, UTF-8 byte length, and SHA-256.
- Native drag remains an advanced fallback. `DataTransferItemList.add(File)` returning `null` is no longer reported as a valid File item.
- Real Chromium regression proves the native download event, suggested filename, saved bytes, and SHA-256.
- No AutoTest rerun is required for the retained v0.57.7 IndexedDB snapshot.

Deployment validation is performed by the canonical GitHub Pages workflow after the tested release lands on `main`.
