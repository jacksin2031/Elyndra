# 世界風格圖鑑與工作室

復原註記（v0.61.3）：下文 v0.61.1／v0.61.2 的測試數字為保留的歷史記錄，不代表本次復原已重跑相同矩陣。六張圖由已確認原 PNG 重新編碼；原 WebP 完整 bytes 基準及事故前完整程式樹仍缺失。本次驗證另列於復原報告。

在世界生成設定第一步的「世界風格」旁開啟圖鑑。11 款內置風格各自展示專屬示意插畫、世界特徵和參數參考；實際世界仍由既有 World Blueprint 與生成器決定。

v0.61.2 移除獨立的「自訂世界」選項及圖鑑卡片。自訂設定統一從「建立自訂樣板」進入；套用樣板後，生成表單顯示「樣板 · 玩家名稱」。這個標記會本地化，玩家名稱保持原文，即使與內建風格同名也不會誤翻譯。內部仍使用既有自訂風格值及欄位傳送故事和進階設定，以保持 Blueprint、舊樣板及存檔相容。

工作室可從目前設定建立自訂風格，指定名稱、示意圖片、風格描述、故事、世界元素及進階參數。儲存內容保留欄位的生成方式和鎖定狀態。角色資料、難度、遊玩時數及已生成的存檔不屬於風格模板。

自訂風格儲存在目前瀏覽器與網站來源的 localStorage，不會同步到其他裝置。清除網站資料會移除風格；不同連接埠的本機網站也使用不同資料區。儲存失敗或資料損壞會顯示錯誤，不會宣稱已保存。

套用風格會更新生成表單，玩家仍可修改並在最後一步確認。內置風格選取保留目前的其他指定設定；圖鑑參數是該風格的參考值。自訂模板會還原其故事與進階設定，不會覆寫玩家角色或難度。

背景動畫只移動獨立的霧光和星塵層，圖片本身、文字及控制項的幾何位置保持不變。支援系統的減少動態效果設定，頁面隱藏時暫停動畫。

## v0.61.2 驗證與交付範圍

本次為本機修改，未部署。9 項資料儲存／舊模板相容／Blueprint 往返測試全部通過；JavaScript 語法檢查 185 個檔案通過。72 個原有生成欄位的 ID、型別、範圍及預設值保留，選項契約只移除經授權的泛用「自訂世界」。

相關測試共 19 項，16 項通過、3 項失敗，沒有跳過。失敗名稱與 v0.61.1 紀錄相同：action grouping、first game reveal localization 及舊 v0.60.32 cache mapping。實際版本與本次 UI 快取版本檢查均通過，沒有將舊版文字比對測試視為新 UI 的驗收證據。

來源資料夾沒有 Git metadata。版本／快取比較及包含圖片的修改檔使用隔離 Git 快照，以已保存本機 v0.61.1 為基準，只覆蓋本次 UI 修改。工作區另有 AI／RPG 模組的外部改動，已保留並從本次 UI 比較及修改檔排除，詳細記錄見 `output/style-refresh/external-changes.json`。這些檢查不是整個目前工作區的發布檢查、GitHub CI 或正式部署的證明。

程式檢查、修改檔及 SHA256 清單位於 `output/style-refresh/`；隔離 Chrome 驗證及截圖位於 `output/playwright/style-refresh/`。瀏覽器只使用 mock 本機 API 及合成測試資料，沒有操作玩家資料或付費 AI 生成。實體手機、其他瀏覽器及正式 AI 世界生成未驗證。

歷史 v0.61.2 圖鑑與模板瀏覽器驗收記錄為 22 項通過，包括 11 張圖片、六款新圖在詳情與生成預覽的一致性、舊樣板完整欄位還原、同名樣板切換語言後保留原名、切回內建風格移除樣板選項，以及合成浮空群島存檔的遊玩背景與減少動態效果。日文在 390／1440px 檢查沒有橫向溢出。追加的語言重測確認日文選取浮空群島、套用永夜寒境，以及切換英文後的 canonical value 和圖片仍然正確。初輪發現及修正後重測的證據均保留在報告中。

世界風格選項另指定固定的 canonical value，語言切換只翻譯標籤，避免圖片映射及 Blueprint 因顯示文字改變而回退。歷史瀏覽器記錄沒有 page error 或外連嘗試；隔離測試的本機 mock API 503 造成五筆 console 記錄，沒有將它描述為零 console error 或正式服務故障。
