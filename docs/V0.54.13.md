# Elyndra v0.54.13 — Runtime Resume & Generation Shape Recovery

This release hardens the AI-generated world/runtime boundary without weakening Engine authority.

## Runtime recovery

- Checkpointed Runtime Expansion remains eligible until its full Geography → Society → Cast → Quest plan is complete, even when the current location count is already satisfied.
- String-form NPC lore is normalized into safe hidden lore instead of aborting Cast canonization.
- Opening Society may recover a missing root `historyRefs` value from its generated faction when the causal reference is already present there.
- Orphan lore-only Cast rows are folded back into the preceding NPC before strict cross-stage link validation.

## Structured generation resilience

- Future generation gets a 3000-token structured-output floor and a 70-second ceiling, plus tighter prose limits, to reduce truncation/retry timeout loops.
- Model JSON repair accepts a missing comma between adjacent object properties while still rejecting unrecoverable JSON syntax.
- Single-operation StatePatch responses recover their transport envelope before the existing capability, revision, and grounding validation runs.
